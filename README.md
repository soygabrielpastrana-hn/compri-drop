# Yo lo Quiero HN (monorepo)
- /server  API Node + Express + Mongoose  (Fase 1)
- /client  React + Vite + Tailwind        (Fase 2)
- /client/src/pages/admin  Panel /admin   (Fase 3)

Primera vez:  npm install && npm run install:all
Variables:    server/.env y client/.env (copiar desde .env.example)
Datos demo:   npm run seed
Desarrollo:   npm run dev      (API en :4000 y tienda en :5173)
